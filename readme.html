PROJECT README

About PurpleLap.

PurpleLap is a beginner-friendly sim-racing learning site. It combines practical driving guides with a wheel and wheelbase catalog, comparison tools, setup advice, and image credits.

Explore the site

  • Home: Start with the guide collection and search for a topic.
  • Gear guide: Browse 58 wheel and wheelbase models, filter by platform or brand, and compare two products side by side.
  • Driving guides: Learn racecraft, cornering, overtaking, car control, tire management, telemetry, and race strategy.
  • Setup and practice: Find advice for controller setup, sim-racing position, building a setup, and finding a comfortable practice rhythm.
  • Photo credits: View image credits, sources, and license details.
  • Feedback: Share feedback about the site.

How comparisons work

The gear guide displays documented product details and produces a short verdict based on available data. It considers meaningful capability differences, such as force-feedback type and listed torque, then documented modular upgrades, price, and included pedals. Unknown or undocumented specifications are not treated as advantages; check platform compatibility and the exact bundle before buying.

Wheel-shape labels describe the rim included with a bundle or state when the product is a wheelbase only. A model’s exact included accessories can vary by platform or package.

Project files

  • *.html — Static site pages; most page content and styling are authored in the page itself.
  • images/ — Editorial and guide photography.
  • assets/wheels/ — Product images used by the gear guide.
  • comparison-verdict.js — Generates comparison recommendations from product facts.
  • comparison-options.js — Keeps a selected product out of the other comparison selector.
  • wheel-shapes.js — Maps catalog model IDs to included wheel-shape descriptions.
  • back-navigation.js — Returns guide back links to the previous page when available.
  • site-ui.js and site-ui.css — Shared footer links and the back-to-top control.
  • photo-credits.js — Image credit data and rendering for the photo credits page.
  • test/ — Focused behavior tests.

Run locally

The site is static and has no build step or package manifest. From the repository root, start a local server:

python3 -m http.server 8000

Then open http://localhost:8000. Stop the server with Ctrl+C.

Run tests

The tests use Node.js’s built-in test runner and need no third-party packages:

node --test test/*.test.js

For a whitespace check, run git diff --check.

Maintaining the site

  • Keep product claims grounded in the facts recorded in gear-guide.html; comparisons should not assume an unlisted feature or compatibility.
  • Keep model IDs consistent between the gear catalog, wheel-shapes.js, and comparison facts.
  • When adding or replacing a local image, update photo-credits.js with the image path and any known creator, source, and license. Mark unknown attribution honestly.
  • Keep interactive controls labeled and pages usable on narrow screens.

Publishing

GitHub Pages serves the repository’s main branch from its root. Merge reviewed changes into main to publish them.
